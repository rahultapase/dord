# Ghost Words

In 1934 Webster's printed a word that never existed: **dord**, a misread slip for
"D or d = density". It stayed in the dictionary until 1947. Editors call these **ghost words**.

Ghost Words is a candlelit horror game that runs on localhost. You tell real forgotten words from
the 1913 Webster's (public domain) apart from fakes that Gemma invents on your laptop. Code, not
the model, decides what is real.

Work in progress. Setup, how to play and credits will be filled in as the build lands.
